## Where do I find my timetable?

_u1/u3/u5460/u940_

Click the "Timetable" tile on the main page. There are 4 available views.The first view displays the up to date timetable for the current day including changes from the substitution, school events, canceled lessons, etc. In this view you can see homeworks/exams assigned for the lessons.The second tab displays up to date timetable for a specific week. The school calendar is in the third view. 
The last tab displays your regular timetable. In this view it is possible to look up regular timetables of other classes.

## Substitutions overview in the mobile application

_u1/u3/u5460/u1015_

Click on the substitution tile. You can see timetable changes that affect you in the first view. In the second view you can see substitutions by individual class. In the third view you can see substitutions by teacher.
